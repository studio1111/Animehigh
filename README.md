# Animehigh

ربات زمان‌بندی‌شده برای پایش فیدهای مجاز، دریافت فایل‌هایی که اجازهٔ دانلود و بازنشرشان را دارید، جلوگیری از انتشار تکراری و آماده‌سازی انتشار در کانال روبیکا.

## وضعیت فعلی

این مخزن از صفر راه‌اندازی می‌شود. برای محافظت از کانال و حساب شما، ربات فقط باید از فیدها و دامنه‌هایی استفاده کند که مجوز دانلود و بازنشر آن‌ها را دارید. این پروژه به‌صورت پیش‌فرض از سایت‌های تورنت یا سایت‌های انتشار غیرمجاز، فایل‌های دارای حق نشر را دانلود و دوباره منتشر نمی‌کند.

## قابلیت‌های برنامه‌ریزی‌شده

- اجرای زمان‌بندی‌شده با GitHub Actions و اجرای دستی
- خواندن RSS/Atom از منابع مجاز
- کنترل شناسه و هش فایل برای جلوگیری از تکرار
- دریافت فایل مستقیم فقط از دامنه‌های مجاز پیکربندی‌شده
- کنترل حد حجم و کامل‌بودن فایل پیش از انتشار
- حفظ وضعیت پردازش در فایل دادهٔ پروژه
- ارسال به روبیکا از طریق API رسمی/مستندشده، پس از پیکربندی توکن و شناسهٔ کانال
- آزمون‌های خودکار و اعتبارسنجی تنظیمات

## راه‌اندازی

1. در GitHub بخش Settings → Secrets and variables → Actions، مقادیر محرمانهٔ موردنیاز را اضافه کنید.
2. در config.example.json فیدهای مجاز و دامنه‌های دانلود را تنظیم و نسخهٔ خود را به config.json تبدیل کنید.
3. مطمئن شوید توکن ربات و شناسهٔ مقصد صحیح‌اند و ربات اجازهٔ ارسال به کانال را دارد.
4. ابتدا اجرای دستی را انجام دهید و گزارش Actions را بررسی کنید؛ سپس انتشار زمان‌بندی‌شده را فعال کنید.

هرگز توکن ربات را در کد یا فایل‌های مخزن قرار ندهید.

## محدودیت GitHub Actions

Runnerهای GitHub برای کارهای زمان‌بندی‌شده و آزمون مناسب‌اند، اما محل ذخیره‌سازی دائمی فایل‌های ویدئویی نیستند. طبق مستندات فعلی روبیکا، آپلود نوع File حداکثر ۵۰ مگابایت و نوع Video نیز فقط MP4 تا حداکثر ۵۰ مگابایت است؛ بنابراین نسخهٔ اولیه سقف دانلود را به‌طور پیش‌فرض ۴۵ مگابایت می‌گذارد و فایل‌های بزرگ‌تر برای ارسال مستقیم در یک پیام مناسب نیستند. MKV در این روش به‌صورت فایل پیوست ارسال می‌شود، نه پخش ویدئویی. برای قسمت‌های حجیم باید از میزبانی مجاز و ارسال لینک استفاده شود یا راهکاری که محدودیت واقعی روبیکا را پشتیبانی کند. زمان اجرای زمان‌بندی‌شده نیز ممکن است با تأخیر همراه باشد.

## مجوز محتوا

این پروژه برای فایل‌های عمومیِ مجاز، محتوای دارای مجوز بازنشر، یا فایل‌هایی که صاحب حق نشر اجازهٔ انتشارشان را داده است طراحی می‌شود.
