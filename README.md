# Animehighbo

ربات زمان‌بندی‌شدهٔ **Animehighbo** برای تلگرام: پایش فیدهای مجاز، دریافت فایل‌هایی که اجازهٔ دانلود و بازنشرشان را دارید، جلوگیری از انتشار تکراری و ارسال فایل به کانال تلگرام.

## وضعیت فعلی

این مخزن برای انتشار محتوای مجاز راه‌اندازی شده است. منابع و دامنه‌های دانلود باید فقط شامل محتواهایی باشند که مجوز انتشارشان را دارید. فیدهای تورنت و منابع انتشار غیرمجاز به‌صورت پیش‌فرض تنظیم نشده‌اند.

## قابلیت‌ها

- اجرای زمان‌بندی‌شده با GitHub Actions هر ۳۰ دقیقه و اجرای دستی
- خواندن RSS/Atom از منابع مجاز
- کنترل شناسه و هش فایل برای جلوگیری از تکرار
- دریافت فایل مستقیم فقط از دامنه‌های HTTPS مجاز پیکربندی‌شده
- کنترل حجم و امضای ابتدایی فایل پیش از ارسال
- ارسال MP4 با Telegram Bot API به روش sendVideo
- ارسال MKV و سایر فرمت‌های پشتیبانی‌شده به روش sendDocument
- نگهداری وضعیت انتشار برای جلوگیری از تکرار در اجراهای بعدی
- آزمون‌های خودکار

## راه‌اندازی

1. با BotFather یک ربات تلگرام بساز.
2. در مخزن GitHub به Settings → Secrets and variables → Actions برو و این Secretها را اضافه کن:
   - `TELEGRAM_BOT_TOKEN`: توکن ربات
   - `TELEGRAM_CHAT_ID`: شناسهٔ کانال یا `@channelusername`
3. ربات را به کانال Animehighbo اضافه کن و دسترسی انتشار پیام بده.
4. فایل `config.json` را با فیدهای مجاز و دامنه‌های مستقیم مربوط به فایل‌های دارای مجوز انتشار تکمیل کن.
5. متغیر مخزن `ANIMEHIGHBO_DRY_RUN` را ابتدا روی `true` قرار بده و اجرای دستی را بررسی کن. فقط پس از بررسی مقصد، مجوز محتوا و تنظیمات، آن را روی `false` قرار بده.

توکن را در کد، فایل‌های مخزن یا پیام‌های عمومی قرار نده.

## محدودیت‌ها

نسخهٔ ابری Telegram Bot API برای آپلود مستقیم فایل محدودیت اندازه دارد؛ این پروژه سقف پیش‌فرض را ۴۵ مگابایت قرار می‌دهد تا کمی حاشیهٔ امن باقی بماند. برای قسمت‌های حجیم‌تر به روش میزبانی و انتشار لینک نیاز است. Runnerهای GitHub برای پردازش زمان‌بندی‌شده مناسب‌اند، اما فضای ذخیره‌سازی دائمی فایل‌های ویدئویی نیستند و اجرای زمان‌بندی‌شده ممکن است با تأخیر شروع شود.

## مجوز محتوا

این پروژه برای فایل‌های عمومیِ مجاز، محتوای دارای مجوز بازنشر، یا فایل‌هایی که صاحب حق نشر اجازهٔ انتشارشان را داده است طراحی می‌شود. برای منابعی مانند SubsPlease و Nyaa.si، ربات به‌طور پیش‌فرض برای دانلود و بازنشر قسمت‌های دارای حق نشر پیکربندی نمی‌شود. می‌توان از منابع قانونی برای اعلان انتشار و لینک رسمی استفاده کرد.
